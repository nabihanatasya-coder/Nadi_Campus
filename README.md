
# NadiCampus – Student Management System

## Project Description
NadiCampus is a responsive, web-based Student Management System developed for the IMS566 individual assignemnt.
The system provides an interactive platform for managing student records, academic courses, and student performance through a modern and user-friendly interface.

## Features

### 1. User Authentication
- Login and Sign Up pages
- Form validation
- Demo login functionality

### 2. Dashboard
- Student statistics and overview
- Interactive data visualisation
- Recent activity tracking

### 3. Student Management
- Add, view, edit, and delete student records
- Search and filter students
- Student status and GPA management

### 4. Course Management
- Add, view, edit, and delete courses
- Search and filter course information
- Manage course credits, semesters, and status

### 5. Academic Performance
- Student GPA overview
- Academic standing classification
- Performance charts and statistics

### 6. Admin Profile
- View and update administrator information

### 7. Responsive Interface
- Desktop and mobile-friendly design
- Interactive sidebar navigation
